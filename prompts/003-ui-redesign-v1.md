# 任务：UI 全面重构 —— 参考 dsh 官方 Web UI 风格

项目：~/development/harness-desktop
基于：001（Phase 0-3 已验收）+ 002（自定义接入已验收）

## 背景
当前 UI 是 codex 自己设计的简单聊天界面（平铺下拉、功能散落、无品牌感），
不符合 owner 的期望。owner 明确要求参考 **DeepSeek Harness 官方 Web UI**
的视觉风格重构，并满足以下布局约定。

## 布局约定（owner 钦定，必须遵守）

```
┌─────────────────────────────────────────────────────┐
│  🐋 harness desktop        ← 左上角品牌区            │
├─────────────────────────────────────────────────────┤
│  💬 会话A  ⟳              ← 会话列表（左侧）          │
│  💬 会话B                   · 会话工作时标签转圈特效    │
│  💬 会话C                   · 像 Hermes 桌面端那样     │
│                                                     │
│             聊天主区域                                │
│          （参考官方 web 视觉风格）                      │
│                                                     │
│  [输入框.....................................]       │
│  ⚙ ← 左下角：设置按钮，所有功能全部收进这里            │
└─────────────────────────────────────────────────────┘
```

### 1. 左上角品牌区
- 放鲸鱼 logo + 文字 "harness desktop"
- 素材已放项目 `build/brand/`：favicon.svg（鲸鱼标志）、wordmark.svg（官方字标）
- 深色主题下 logo 用白色版本，浅色下用深色版本（参考官方 favicon 的 prefers-color-scheme 逻辑）

### 2. 左侧会话列表
- 会话标签在工作（agent 正在跑 turn）时显示**转圈加载特效**
- 参考 Hermes 桌面端：会话项上有旋转 spinner 或 loading 指示
- 实现：根据已订阅会话的 running 状态，给对应会话项加 CSS 动画（如旋转图标/进度环）
- 状态来源：现有 SessionStreamEvent 里的 running 事件（001 已有）

### 3. 左下角设置（核心变更）
- 所有功能**全部收进设置**，主界面不铺开任何功能入口
- 设置里至少包含（来自 001/002 已有能力）：
  - 引擎状态（端口/版本/就绪）
  - API Key 管理（DeepSeek + 其他 provider）
  - 自定义接入（002 已做的 CustomProviders 组件，原样保留）
  - 工作区选择
  - 默认模型
- 未来扩展位（本提示词不实现，只留好结构）：记忆、定时任务、消息通道、技能库

### 4. 聊天主区域（参考官方 web 风格）
- 视觉参考：DeepSeek Harness 官方 Web UI 的配色/圆角/卡片/排版体系
- 官方主题 token 参考：`~/dsh-src/packages/client/ui-theme/src/styles/`（--dsw-* 语义 token，深色为主）
- 不必 1:1 复刻官方组件，但要**风格一致**：深色底、圆角卡片、消息气泡、流式输出
- 保留现有功能：流式消息、工具调用（可升级为卡片展示）、模型切换（002 的两级选择）、停止按钮

## 技术约束（延续 001/002）
- adapter 隔离原则不变：renderer 只走 IPC，不碰 dsh wire 格式
- 锁 @deepseek-ai/dsh@0.1.0-rc.6 不变
- 不引入重型 UI 库（官方也是手写 CSS），继续用现有 CSS 体系重构
- TypeScript 严格模式，pnpm typecheck 必须零错误

## 验收标准（owner 实测）
1. 启动后左上角显示鲸鱼 logo + "harness desktop"，深色主题下清晰可见
2. 主界面 = 品牌区 + 会话列表 + 聊天区，无任何散落功能按钮
3. 左下角有设置按钮，点开包含：引擎状态/API Key/自定义接入/工作区/默认模型
4. 会话工作时左侧标签转圈，结束后停转
5. 整体视觉与官方 dsh Web UI 风格一致（深色、圆角、干净）
